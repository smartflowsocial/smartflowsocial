# SmartFlowSocial 0.1.0-alpha.1

15 November 2026. These notes are for the commit that contains them. The tag `v0.1.0-alpha.1` is not
created by this change.

`package.json` version is `0.1.0-alpha.1`. The package is `"private": true`. Do not publish it to
npm.

## Why this alpha exists

`v0.1.0-alpha.0` built a worker bundle from `pnpm dev` and did not run it. Later commits on `main`
start the worker, load `.env` before validation, and install the Docker image with pnpm. This alpha
also binds development databases to localhost, separates self-hosted software from hosted plans, and
adds a relay delivery check.

## What changed since v0.1.0-alpha.0

- `pnpm dev` starts one web server and one worker. `pnpm start` stops both if either exits.
- Development `docker-compose.yml` publishes Postgres on `127.0.0.1:5433` and Redis on
  `127.0.0.1:6379`. The image is `postgres:16`.
- `SELF_HOSTED=true` removes hosted-plan caps for software this process runs. Leave it unset on
  managed hosting. It does not include hosted Blossom or hosted Blastr.
- Referral payouts are opt-in. Production with an existing `OWNER_NWC` and an unset flag still pays
  and logs a warning. Set the flag to `true` or `false` on that host. The compatibility path stays
  until that is done.
- `pnpm test:relay-publish` delivers one signed event to a loopback relay.
- Settings exports account JSON and deletes the account. Relays keep events they already accepted.
- Account deletion removes the public key from referral rows. Pending and failed commissions with no
  in-flight claim are removed. Paid rows stay, with the key replaced, until the retention purge.
- Referral payout invoices that stay valid for more than 365 days are refused.
- React Router stays on 6.30.6. The two moderate advisories still need React Router 7. That
  migration is not in this alpha.

## Known limitations

- Hosted plan limits still apply when `SELF_HOSTED` is unset.
- Deleting an account does not delete Nostr events from relays. It deletes unshared objects in this
  install's own bucket. Blossom blobs and files on other servers remain.
- Retained payment rows and referral payout audit rows are deleted after 365 days. The worker does
  that every 24 hours, and `POST /cron/purge-retained-records` does it on demand. `GET` still works.
  365 days is the software setting, not a legal conclusion.
- The legal identity of the hosted operator and the providers are not decided in this repository.
- No tag is published in this repository until the owner tags this commit.

## Release check

```bash
pnpm check:compose
pnpm exec prisma generate
pnpm typecheck:app
pnpm test:unit
pnpm exec vitest run tests/integration/relay-publisher.contract.test.ts
pnpm docker
pnpm exec prisma migrate deploy
pnpm smoke:publish
pnpm test:relay-publish
```

`pnpm smoke:publish` and `pnpm test:relay-publish` need Postgres and Redis. They create an ephemeral
key and delete that user. They do not use a public relay or a wallet.
