# SmartFlowSocial 0.1.0-alpha.2

16 November 2026. These notes describe that snapshot. Do not tag `v0.1.0-alpha.2`. The commission
paragraph below was superseded before publication by [0.1.0-alpha.3](./v0.1.0-alpha.3.md): hosted
Starter is 7.5%, and a self-hosted install charges 0%.

`package.json` version is `0.1.0-alpha.2`. The package is `"private": true`. Do not publish it to
npm.

`v0.1.0-alpha.1` was prepared and not tagged. This alpha is the next one because the running
application is React Router 8.5.1 and React 19.2.7, and because payout safety changed.

## What changed

- React Router 8 and React 19 are the application stack. There is no Remix runtime.
- Campaign and referral Lightning payouts refuse a BOLT11 invoice unless the decoded amount is the
  exact authorized whole-sat amount, on Bitcoin mainnet, unexpired, and carrying a payment hash.
- A campaign payout is claimed before `pay_invoice`. A timeout or a lost reply becomes `paying` or
  `unknown`. Automatic retry does not send another payment. `lookup_invoice` can confirm a payment
  the wallet already settled. If lookup cannot prove that, an operator has to resolve it. See
  [Payout reconciliation](../security/payout-reconciliation.md).
- `REFERRAL_PAYOUTS_ENABLED` must be `true`, `1`, or `yes`. `OWNER_NWC` no longer turns payouts on.
- Fresh `prisma migrate deploy` creates the plan rows the pricing migration expected.
- The invoice charges a 10% finalization fee on Free and 5% on Creator. Starter, Pro, Teams, and
  Founder are 0%. The public pricing and terms pages do not say that yet.

## Upgrade

Set `REFERRAL_PAYOUTS_ENABLED=true` before upgrading a host that paid referrals because `OWNER_NWC`
was set and the flag was unset. Otherwise those payouts stop.

Apply migrations with `pnpm exec prisma migrate deploy`. Do not use `prisma db push` on a database
that already has data.

After deploy, look for `PayoutItem` rows in `paying` or `unknown`, and referral audit rows in
`unknown` or `started`. Do not pay those again until the wallet is checked.

## Known limitations

- Not every wallet implements `lookup_invoice`. Those payouts stay unknown. There is no dashboard
  button for the operator decision. The function is `resolveUnknownCampaignPayoutItem`.
- The marketing site is a separate private repository. Pull request
  [smartflowsocial-landing#2](https://github.com/smartflowsocial/smartflowsocial-landing/pull/2)
  updates the fee and privacy copy. It is not merged, and the live site was not redeployed. Privacy
  still has no legal name or address.
- `pnpm test:relay-publish` delivers one event to a loopback relay through
  `scripts/relay-publisher.mjs`. That is not the Cloudflare publisher worker.
- A self-hosted Free account is still quoted the 10% finalization fee.
- `pnpm audit` still reports moderate `minimatch` 10.2.6 in `@react-router/fs-routes`. That is a
  development tool. `pnpm audit --prod` is clean.
- Account deletion does not remove events from relays. It keeps payment facts, without the public
  key, for 365 days.

## Release check

Automated, from this repository:

```bash
pnpm install --frozen-lockfile
pnpm exec prisma generate
pnpm typecheck
pnpm test:unit
pnpm test:security
pnpm audit --prod
pnpm docker
pnpm exec prisma migrate deploy
pnpm test:relay-publish
```

`pnpm test:relay-publish` needs loopback Postgres and Redis. It creates an ephemeral key and deletes
that user. It does not use a public relay or a wallet.

Human, before the tag:

- Confirm the payout tests in this note still describe the code.
- Read [hosted service disclosures](../legal/hosted-service-disclosures.md) and either publish the
  replacement text or decide not to.
- Confirm production `REFERRAL_PAYOUTS_ENABLED` if referral payouts should continue.
- Confirm GitHub branch protection, organization 2FA, and Cloudflare token scopes outside this
  repository.
- Do not enable campaign autopay against a mainnet wallet until an operator has watched one
  unknown-outcome drill.
