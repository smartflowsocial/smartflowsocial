# v1.0.0-rc.1

Release candidate for public testing. This is not stable `v1.0.0`. Do not tag `v1.0.0` from this
note.

`package.json` is `1.0.0-rc.1`. The record is
[`v1.0.0-rc.1.manifest.json`](./v1.0.0-rc.1.manifest.json). This commit leaves
`applicationReleaseSha` null. The tag SHA is recorded in a later commit, and that later commit is
not the tag.

`v1.0.0-beta.2` remains `5be28add1a8ef1d078e8ba9c885ca68249d0a54f`. Its `package.json` says
`1.0.0-beta.1`. This candidate is the source after that tag. It is not a description of the tagged
tree.

## Why this is a release candidate

`v1.0.0-beta.2` is already published. `develop` after that tag removes the external HTTP publisher
and the cache worker, and a fresh install is self-hosted unless `SFS_DEPLOYMENT_MODE=hosted`. Those
are the changes a stable `v1.0.0` would ship. An rc keeps that candidate explicit without publishing
`v1.0.0`.

## What this candidate contains

- `SFS_DEPLOYMENT_MODE` is `self_hosted` or `hosted`. An empty mode is self-hosted, including a
  production build. `SELF_HOSTED` is not a selector. A non-empty `SELF_HOSTED` refuses to boot.
- Signed events are published from this process. Profile and thread reads run in this process and
  cache in Redis. That does not operate a full Nostr indexer.
- A retryable publish failure returns the scheduled row to `SCHEDULED`. A negative relay
  acknowledgement stays `FAILED`.
- `app.smartflow.social` and `staging.smartflow.social` refuse to start unless the mode is `hosted`.
- Self-hosted commission is 0% on every plan. Hosted commission stays Free 10%, Starter 7.5%,
  Creator 5%, and 0% on Pro, Teams, and Founder.
- A linked child follows the parent plan for the Blastr badge and for whether publishes include the
  Blastr relay. The child's own switch still has to be on.

## Companions

Blossom is optional. A self-hosted install does not include it. Blastr is a separate hosted fan-out
service. The internal publisher and the internal reader are in this repository. NostrMash gateways
are not dependencies of this release. Companion tags are `v1.0.0-rc.1` in their own repositories.
This file does not copy their commit SHAs. The GitHub Release records those SHAs after the companion
tags exist.

## Install this candidate

Use this checkout, not the beta.2 tag. Node.js 26.13.1 or newer, pnpm 12.21.0, PostgreSQL, and
Redis. `pnpm docker` starts Postgres and Redis only.

```bash
pnpm install
cp example.env .env
pnpm docker
pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm dev
```

`example.env` sets `SFS_DEPLOYMENT_MODE=self_hosted`. Do not set `NOSTR_PUBLISHER_URL`,
`PRIMAL_CACHING_URL`, or `SELF_HOSTED`.

To install the published prerelease instead, check out `v1.0.0-beta.2` and follow the README in that
commit. Its instructions still use `SELF_HOSTED=true` and still describe optional HTTP adapters.
